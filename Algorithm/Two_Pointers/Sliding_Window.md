# 슬라이딩 윈도우 (Sliding Window)

## 1. 개념

**슬라이딩 윈도우(Sliding Window)** 는 배열이나 문자열에서 연속된 구간(Window)을 이동시키며 필요한 값을 계산하는 알고리즘이다.

이전 구간에서 계산한 결과를 재활용하여 불필요한 중복 연산을 줄인다.

### 핵심 원리

```text
배열: [1, 2, 3, 4, 5]
윈도우 크기: 3

[1, 2, 3] 4 5 → 합계 6
 1 [2, 3, 4] 5 → 합계 9
 1  2 [3, 4, 5] → 합계 12
```

구간을 한 칸 이동할 때마다 전체 합을 다시 계산하는 대신,

**현재 합 = 이전 합 - 빠지는 값 + 새로 들어오는 값**

```python
current -= arr[left]   # 왼쪽 값 제거
current += arr[right]  # 오른쪽 값 추가
```

---

## 2. 슬라이딩 윈도우의 종류

### ① 고정 크기 슬라이딩 윈도우 (Fixed Size)

- 윈도우의 크기 K가 고정되어 있다.
- 한 칸 이동할 때 왼쪽 원소 하나를 제거하고 오른쪽 원소 하나를 추가한다.
- 대표 유형: 크기가 K인 연속 부분 배열의 최대 합

**구현 템플릿**

```python
arr = [2, 1, 5, 1, 3, 2]
K = 3

# 첫 번째 구간의 합
current = sum(arr[:K])
result = current

# 한 칸씩 이동
for right in range(K, len(arr)):
    current -= arr[right-K]  # 빠지는 값
    current += arr[right]    # 들어오는 값

    result = max(result, current)

print(result)  # 9
```

**인덱스 이해**

```text
K = 3

첫 구간: [0, 1, 2]
다음 구간: [1, 2, 3]

right = 3
빠지는 인덱스 = right - K = 0
들어오는 인덱스 = right = 3
```

K가 구간에 포함되는 원소 개수일 때 다음 공식을 사용한다.

```python
current = current - arr[right-K] + arr[right]
```

### ② 가변 크기 슬라이딩 윈도우 (Variable Size)

- 윈도우의 크기가 조건에 따라 변한다.
- `right`를 이동하며 구간을 확장한다.
- 특정 조건에 따라 `left`를 이동하며 구간을 축소한다.
- 대표 유형: 합이 S 이상인 가장 짧은 연속 부분 배열

**구현 템플릿**

다음 코드는 양수로 이루어진 배열에서 합이 `target` 이상인 최소 길이를 구한다.

```python
arr = [2, 3, 1, 2, 4, 3]
target = 7

left = 0
current = 0
result = float('inf')

for right in range(len(arr)):
    current += arr[right]  # 구간 확장

    while current >= target:
        result = min(result, right-left+1)

        current -= arr[left]  # 구간 축소
        left += 1

print(result if result != float('inf') else 0)
# 출력: 2
```

**동작 원리**

1. `right`를 증가시키며 값을 더한다.
2. 구간 합이 목표 이상이면 길이를 갱신한다.
3. `left`를 증가시켜 구간을 줄인다.
4. 조건을 만족하는 동안 반복한다.

주의: 위와 같이 구간 합으로 확장·축소를 결정하는 방식은 양수 또는 음이 아닌 수라는 조건이 중요하다. 음수가 포함되면 합의 변화가 일정하지 않아 같은 방식으로 처리할 수 없는 문제가 있다.

## 3. 슬라이딩 윈도우를 사용하는 이유

### 일반적인 완전탐색

```python
for i in range(N-K+1):
    current = sum(arr[i:i+K])
```

매번 K개의 원소를 다시 더하므로 시간복잡도는 **O(N × K)** 이다.

### 슬라이딩 윈도우

```python
current = sum(arr[:K])

for right in range(K, N):
    current -= arr[right-K]
    current += arr[right]
```

첫 구간만 직접 계산하고, 이후에는 두 값만 갱신하므로 시간복잡도는 **O(N)** 이다.

| 구분 | 완전탐색 | 슬라이딩 윈도우 |
|---|---|---|
| 계산 방식 | 구간 전체 재계산 | 이전 결과 재활용 |
| 구간당 계산 | O(K) | O(1) |
| 전체 시간 | O(N × K) | O(N) |
| 추가 공간 | O(K), 슬라이싱 사용 시 | O(1) |

*고정 크기 구간 합을 구하는 경우를 기준으로 비교한다.*

---

## 4. 슬라이딩 윈도우 vs 투 포인터

| 구분 | 슬라이딩 윈도우 | 투 포인터 |
|---|---|---|
| 핵심 | 연속 구간의 정보 유지·갱신 | 두 포인터를 이동하며 탐색 |
| 구간 크기 | 고정 또는 가변 | 문제에 따라 다름 |
| 대표 유형 | 연속 구간 최대 합 | 정렬 배열에서 두 수의 합 |

슬라이딩 윈도우는 투 포인터를 활용하는 기법 중 하나로 볼 수 있다. 단순히 포인터를 이동시키는 것뿐 아니라 **현재 구간의 정보를 유지하고 재활용하는 것**이 핵심이다.

## 5. 언제 사용하면 좋을까?

다음 특징이 나타나면 슬라이딩 윈도우를 고려한다.

- **연속된 구간**을 탐색하는 문제
- 일정 크기의 구간에서 최대 합, 최소 합 등을 구하는 문제
- 특정 조건을 만족하는 연속 부분 배열이나 부분 문자열을 찾는 문제
- 인접한 구간끼리 중복되는 원소가 많은 문제
- 구간을 이동하면서 필요한 값을 효율적으로 갱신할 수 있는 문제

모든 연속 구간 문제가 슬라이딩 윈도우로 해결되는 것은 아니다. 구간의 크기와 조건, 값의 특성을 함께 확인해야 한다.

## 6. 구현 시 주의사항

### ① K가 무엇을 의미하는지 확인하기

**K가 원소의 개수인 경우**

```text
K = 3
구간: [1, 2, 3]
```

```python
current -= arr[right-K]
```

**K가 양 끝 인덱스의 차이인 경우 (양 끝 포함)**

```text
K = 3
구간: [1, 2, 3, 4]
```

```python
current -= arr[right-K-1]
```

- 원소의 개수: `right - left + 1`
- 양 끝 인덱스의 차이: `right - left`

### ② 첫 구간을 먼저 계산하기

고정 크기 윈도우에서는 첫 번째 구간의 합을 초기화한 뒤 이동해야 한다.

```python
current = sum(arr[:K])
result = current
```

### ③ 범위와 예외 확인하기

- K가 배열의 길이보다 크거나 0일 수 있는가?
- 구간의 양 끝을 포함하는가?
- 반복문이 한 번도 실행되지 않는 경우가 있는가?
- 최댓값과 최솟값 중 무엇을 구하는가?
- 가변 크기라면 구간을 확장·축소하는 조건이 올바른가?

## 7. 핵심 요약

| 유형 | 핵심 동작 | 시간복잡도 |
|---|---|---|
| 고정 크기 | 왼쪽 제거 + 오른쪽 추가 | O(N) |
| 가변 크기 | 조건에 따라 확장·축소 | O(N), 각 포인터가 한 방향으로 이동하는 전형적인 경우 |

**기억할 공식**

```python
# 고정 크기 K의 구간 합
current = sum(arr[:K])

for right in range(K, len(arr)):
    current += arr[right] - arr[right-K]
```

**핵심: 연속된 구간을 이동할 때 이전 결과를 버리지 않고 재활용한다.**
