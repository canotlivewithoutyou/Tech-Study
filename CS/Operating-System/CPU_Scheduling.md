# CPU 스케줄링 (CPU Scheduling)

## 1. 스케줄링

**여러 프로세스의 CPU 처리 순서를 결정하는 방법**이다.

## 2. 선점형 (Preemptive)

- 운영체제가 실행 중인 프로세스의 CPU를 **강제로 회수**할 수 있다.
- 프로세스의 CPU 사용을 유연하게 조정할 수 있으나, 문맥 교환에 따른 **오버헤드**가 발생할 수 있다.

| 종류                                             | 설명                                                                                                                                        |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **RR (Round Robin)**                             | 우선순위 구분 없이 일정 **시간 할당량(Time Quantum)**만큼 CPU를 번갈아 배분한다. 공평한 자원 분배에 유리하다.                               |
| **SRT (Shortest Remaining Time)**                | SJF의 선점형 변형. **남은 실행 시간이 가장 짧은** 프로세스에 CPU를 우선 할당한다.                                                           |
| **다단계 큐 (Multilevel Queue)**                 | 프로세스를 그룹별로 분리하여 **서로 다른 준비 큐**를 두고, 큐마다 서로 다른 스케줄링 정책을 적용한다. 큐 간 고정 우선순위를 사용할 수 있다. |
| **다단계 피드백 큐 (Multilevel Feedback Queue)** | 프로세스가 **여러 단계의 큐 사이를 이동**할 수 있다. 일반적으로 우선순위가 낮아질수록 시간 할당량이 커지도록 구성할 수 있다.                |

## 3. 비선점형 (Non-preemptive)

- 실행 중인 프로세스로부터 운영체제가 **강제로 CPU를 빼앗지 않는다**.
- 구현이 단순하며 문맥 교환 오버헤드가 적을 수 있지만, 긴 작업으로 인해 다른 작업의 대기 시간이 길어질 수 있다.

| 종류                                  | 설명                                                                                     |
| ------------------------------------- | ---------------------------------------------------------------------------------------- |
| **FCFS (First Come First Serve)**     | 프로세서에 **도착한 순서대로** 처리한다. FIFO 방식이다.                                  |
| **SJF (Shortest Job First)**          | 준비 상태의 프로세스 중 **실행 시간이 가장 짧은** 작업부터 처리한다.                     |
| **HRN (Highest Response Ratio Next)** | **응답률이 가장 높은** 프로세스를 먼저 처리한다. 긴 작업에 불리한 SJF의 단점을 보완한다. |

### HRN 우선순위 계산

\[
\text{우선순위(응답률)} = \frac{\text{대기시간} + \text{서비스시간}}{\text{서비스시간}}
\]

- **대기시간**이 길수록 응답률이 증가한다.
- 서비스시간이 짧을수록 응답률이 커지기 쉽다.
- 따라서 짧은 작업을 선호하면서도 오래 대기한 작업의 기아 현상을 완화한다.

## 실기 암기 포인트

- RR = **시간 할당량**
- SRT = **남은 실행 시간 최소 + 선점형**
- 다단계 큐 = **큐별로 분리, 일반적으로 고정 큐**
- 다단계 피드백 큐 = **큐 간 이동 가능**
- FCFS = **도착 순서**
- SJF = **짧은 작업 우선**
- HRN = **(대기시간 + 서비스시간) / 서비스시간**
