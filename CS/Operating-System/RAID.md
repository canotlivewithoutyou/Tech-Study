# RAID (Redundant Array of Inexpensive Disks)

## 1. RAID란?

**RAID (Redundant Array of Inexpensive Disks)**

- 여러 개의 디스크를 **하나의 디스크처럼 관리**하는 기술이다.
- 주로 서버의 저장장치 구성에 사용된다.
- RAID 구성 방식에 따라 **데이터 안정성, 복구 용이성, 전송 성능**을 높일 수 있다.
- RAID **레벨(Level)**에 따라 저장 방식, 중복 여부, 신뢰성 및 효율성이 달라진다.

## 2. RAID의 핵심 저장 방식

### ① 스트라이핑 (Striping)

- 데이터를 **여러 개의 디스크로 분할**하여 나누어 저장하는 방식이다.
- 여러 디스크에 분산하여 읽고 쓸 수 있으므로 **성능 향상**에 유리하다.
- **스트라이핑만 사용하는 경우**, 디스크 하나가 손상되면 데이터를 복구할 수 없다.

### ② 미러링 (Mirroring)

- 동일한 데이터를 **두 개의 디스크에 중복 저장**하는 방식이다.
- 한쪽 디스크가 손상되더라도 다른 쪽 디스크를 이용하여 **복구할 수 있다**.
- 중복 저장으로 인해 사용 가능한 저장 용량이 줄어든다.

## 3. RAID 레벨별 특징

| RAID 레벨 | 구성 방식 | 핵심 특징 |
|:---:|---|---|
| **RAID 0** | 스트라이핑 | **중복 저장 X, 에러 검출·복구 기능 X**. 디스크 분산 저장으로 성능 향상에 유리 |
| **RAID 1** | 미러링 | **중복 저장 O**, 동일한 데이터를 복제하여 **높은 신뢰도** 확보 |
| **RAID 2** | 스트라이핑 | **해밍 코드(Hamming Code)**를 활용한 오류 검출·정정 |
| **RAID 3** | 스트라이핑 | **바이트 단위**로 데이터를 분산 저장하고, **패리티**로 오류 검증·복구 지원 |
| **RAID 4** | 스트라이핑 | RAID 3과 유사하나, 데이터를 **블록 단위**로 분할 저장 |
| **RAID 5** | 스트라이핑 + 분산 패리티 | **패리티 블록을 각 디스크에 분산 저장** |
| **RAID 6** | 스트라이핑 + 이중 패리티 | **패리티 정보를 이중으로 구성**하여 디스크 2개 장애까지 복구 가능 |

### 구분해서 기억하기

- **RAID 0 vs RAID 1**: 스트라이핑(성능, 중복 X) ↔ 미러링(중복 O, 신뢰성)
- **RAID 2**: 해밍 코드
- **RAID 3 vs RAID 4**: **바이트 단위** ↔ **블록 단위**
- **RAID 5 vs RAID 6**: **분산 패리티** ↔ **이중 패리티**
