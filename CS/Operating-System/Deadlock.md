# 교착상태 (Deadlock)

## 1. 교착상태란?

**둘 이상의 프로세스가 서로 점유한 자원을 요구하며 무한정 대기하는 상태**를 말한다.

## 2. 교착상태 발생의 필요조건 4가지

다음 **네 조건이 모두 성립해야** 교착상태가 발생할 수 있다. 모두 성립한다고 해서 반드시 교착상태가 발생하는 것은 아니다.

| 조건                             | 의미                                                            |
| -------------------------------- | --------------------------------------------------------------- |
| **상호 배제 (Mutual Exclusion)** | 한 번에 한 프로세스만 특정 자원을 사용할 수 있음                |
| **점유 및 대기 (Hold and Wait)** | 하나 이상의 자원을 점유한 채 다른 자원을 기다림                 |
| **비선점 (No Preemption)**       | 다른 프로세스가 점유한 자원을 강제로 빼앗을 수 없음             |
| **환형 대기 (Circular Wait)**    | 프로세스들이 원형으로 연결된 형태로 서로가 점유한 자원을 요청함 |

## 3. 교착상태 해결 방법

| 방법                  | 설명                                                                                                        |
| --------------------- | ----------------------------------------------------------------------------------------------------------- |
| **예방 (Prevention)** | 발생에 필요한 **4가지 조건 중 하나 이상이 성립하지 않게** 하여 사전 예방                                    |
| **회피 (Avoidance)**  | 자원 요청 때 시스템의 **안전 상태**를 유지하도록 판단하고 할당. 예: **은행원 알고리즘(Banker's Algorithm)** |
| **발견 (Detection)**  | 교착상태가 발생했는지를 프로세스와 자원 할당 관계 등을 통해 탐지                                            |
| **회복 (Recovery)**   | 교착상태 프로세스 종료, 자원 선점·회수 등을 통해 상태 해결                                                  |

### 은행원 알고리즘

- 교착상태 **회피** 알고리즘이다.
- 각 프로세스의 최대 자원 요구량, 현재 할당량, 가용 자원을 고려한다.
- 자원을 할당한 뒤에도 모든 프로세스가 완료 가능한 **안전 순서(Safe Sequence)**가 존재할 때만 할당한다.
- 은행이 모든 고객의 최대 인출 요구를 만족시킬 수 있는지 검토하며 현금을 할당하는 상황에 비유한다.

## 실기 암기 포인트

- 필요조건 네 가지: **상호 배제 / 점유 및 대기 / 비선점 / 환형 대기**
- 예방 = **조건 제거**
- 회피 = **안전 상태 유지 / 은행원 알고리즘**
- 발견 = **교착 탐지**
- 회복 = **종료·자원 회수**
