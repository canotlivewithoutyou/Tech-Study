# 운영체제 종류와 UNIX 구성 요소

## 1. 운영체제 종류

| 운영체제 | 특징 |
| --- | --- |
| **Windows** | 마이크로소프트(Microsoft)에서 개발한 운영체제 |
| **UNIX** | 미국 AT&T 벨 연구소에서 개발한 운영체제. **커널(Kernel)**과 **셸(Shell)** 등의 요소로 구성 |
| **Linux** | 리누스 토르발스(Linus Torvalds)가 개발을 시작한 **유닉스 계열(Unix-like) 운영체제 커널**을 기반으로 하는 운영체제 |
| **macOS / iOS** | 애플에서 개발한 운영체제. UNIX 계열 기술을 기반으로 함 |
| **Android** | 구글이 주도하여 개발한 **리눅스 커널 기반** 모바일 운영체제 |

> **구분:** UNIX와 Linux는 동일한 운영체제가 아니다. Linux는 UNIX와 유사한 구조와 사용 방식을 가진 *유닉스 계열* 운영체제이다.

## 2. UNIX 구성 요소

### 2.1 커널(Kernel)

운영체제의 핵심 부분으로, **하드웨어와 프로그램 사이에서 자원을 관리**한다.

- 하드웨어 보호 및 프로그램과 하드웨어 사이의 인터페이스 제공
- **프로세스 관리**: 프로세스 생성, 실행 및 스케줄링
- **기억장치(메모리) 관리**
- **파일 관리**
- **입출력(I/O) 관리**
- 데이터 전송 및 변환 등의 시스템 기능 제공
- 셸 프로그램과 응용프로그램이 시스템 기능을 이용하도록 지원

### 2.2 셸(Shell)

사용자의 명령을 해석해 운영체제에 전달하는 **사용자 인터페이스(명령어 해석기)**이다.

- 사용자가 입력한 명령을 인식하고 해석하여 실행
- 필요한 시스템 기능을 커널에 요청
- 명령을 조합하고 반복 실행하는 **셸 스크립트** 기능 제공
- 초기화 파일 등을 이용하여 사용자 실행 환경 설정

### 2.3 커널과 셸의 차이

| 구분 | 커널(Kernel) | 셸(Shell) |
| --- | --- | --- |
| 역할 | 시스템 자원 관리 및 하드웨어 제어 | 사용자 명령 해석 및 실행 요청 |
| 관점 | 프로그램 ↔ 하드웨어 | 사용자 ↔ 운영체제 |
| 주요 기능 | 프로세스·메모리·파일·입출력 관리 | 명령 실행, 스크립트, 환경 설정 |

**명령 실행 흐름**

```text
사용자 → 셸(Shell) → 커널(Kernel) → 하드웨어
```

> 실제 응용프로그램도 시스템 호출을 통해 커널 기능을 사용할 수 있다. 모든 요청이 반드시 셸을 거치는 것은 아니다.

## 3. UNIX 셸 환경 관련 명령어

| 명령어 | 개념 |
| --- | --- |
| `set` | 현재 셸의 변수 및 설정 확인·변경(셸 종류에 따라 동작 차이) |
| `env` | 환경변수를 표시하거나 지정한 환경에서 명령 실행 |
| `printenv` | 환경변수의 값을 출력 |
| `setenv` | 주로 C 셸(`csh`, `tcsh`)에서 환경변수 설정 |

> **주의:** `setenv`는 일반적인 `bash` 명령이 아니다. `bash`에서는 주로 `export 변수명=값`을 사용한다.

## 4. 시험 핵심 정리

- **커널**: 프로세스·메모리·파일·입출력 등 **시스템 자원 관리**
- **셸**: 사용자 **명령어 해석 및 전달**, 셸 스크립트 지원
- **Linux**: UNIX와 동일하지 않으며, **유닉스 계열 운영체제**
- **Android**: **리눅스 커널 기반** 모바일 운영체제
