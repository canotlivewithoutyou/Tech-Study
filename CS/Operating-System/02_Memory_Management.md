# 기억장치 관리 전략과 메모리 분할

## 1. 기억장치 관리 전략

기억장치 관리 전략은 **반입(Fetch)**, **배치(Placement)**, **교체(Replacement)** 전략으로 구분한다.

| 분류 | 종류 | 내용 |
| --- | --- | --- |
| **반입 전략(Fetch)** | **요구 반입(Demand Fetch)** | 특정 프로그램이나 데이터를 **실제로 요구할 때** 주기억장치에 적재 |
| | **예상 반입(Anticipatory Fetch)** | 앞으로 참조할 것으로 예상되는 프로그램이나 데이터를 **미리** 적재 |
| **배치 전략(Placement)** | **최초 적합(First Fit)** | 들어갈 수 있는 **첫 번째** 가용 공간에 배치 |
| | **최적 적합(Best Fit)** | 들어갈 수 있는 공간 중 **가장 작은** 공간에 배치해 남는 공간을 최소화 |
| | **최악 적합(Worst Fit)** | 들어갈 수 있는 공간 중 **가장 큰** 공간에 배치 |
| **교체 전략(Replacement)** | **FIFO, OPT, LRU, LFU, NUR 등** | 새 데이터나 페이지를 적재하기 위해 기존 데이터를 교체할 대상 결정 |

> **표현 주의:** 최적 적합은 선택된 빈 공간의 **남는 크기**를 최소화한다는 뜻이고, 최악 적합은 **가장 큰 빈 공간을 선택**한다는 뜻이다. 실제 외부 단편화의 총량을 항상 최소화하거나 최대화한다고 단정할 수는 없다.

### 배치 전략 암기

```text
First Fit : 처음 발견한 사용 가능 공간
Best Fit  : 들어갈 수 있는 공간 중 가장 작은 공간
Worst Fit : 들어갈 수 있는 공간 중 가장 큰 공간
```

## 2. 메모리 분할 기법

### 2.1 페이징(Paging)

- 프로그램의 가상 주소 공간을 **동일한 크기**의 **페이지(Page)**로 분할
- 물리 메모리를 같은 크기의 **페이지 프레임(Page Frame)**으로 분할
- 페이지를 사용 가능한 페이지 프레임에 배치하여 실행
- **페이지 테이블(Page Table)**을 통해 가상 페이지와 물리 프레임의 주소를 매핑
- **내부 단편화(Internal Fragmentation)** 발생 가능

#### 페이지 크기에 따른 특성

| 구분 | 작은 페이지 크기 | 큰 페이지 크기 |
| --- | --- | --- |
| 내부 단편화 | 감소하는 경향 | 증가하는 경향 |
| 페이지 테이블 크기 | 커지는 경향 | 작아지는 경향 |
| 페이지 수 | 증가 | 감소 |
| 매핑·관리 부담 | 증가할 수 있음 | 감소할 수 있음 |
| I/O 특성 | 작은 단위로 읽지만 I/O 횟수가 늘 수 있음 | 큰 단위로 읽어 I/O 횟수는 줄 수 있지만 불필요한 데이터 적재 가능 |

작은 페이지는 필요한 데이터만 적재하기 쉬워 **워킹 셋(Working Set)**을 효율적으로 유지하는 데 유리할 수 있지만, 페이지 테이블과 입출력 관리 비용이 증가할 수도 있다.

> **주의:** 캡처의 ‘작은 페이지일수록 페이지 이동 시간이 감소한다’와 ‘큰 페이지일수록 입출력 시간이 감소한다’는 문장은 상황에 따라 달라진다. 페이지 크기와 성능은 I/O 횟수, 전송량, 페이지 테이블 관리 비용 등을 함께 고려해야 한다.

### 2.2 세그먼테이션(Segmentation)

- 프로그램을 **서로 다른 크기**의 **논리적 단위**로 분할
- 분할된 단위를 **세그먼트(Segment)**라고 함
- 세그먼트 단위로 기억장치에 배치하고 실행
- **외부 단편화(External Fragmentation)** 발생 가능

### 2.3 페이징과 세그먼테이션 비교

| 구분 | 페이징(Paging) | 세그먼테이션(Segmentation) |
| --- | --- | --- |
| 분할 기준 | **고정 크기** | **가변 크기**의 논리적 단위 |
| 분할 단위 | 페이지(Page) | 세그먼트(Segment) |
| 주된 단편화 | **내부 단편화** | **외부 단편화** |
| 주소 관리 | 페이지 테이블 | 세그먼트 테이블 |

### 단편화 용어

- **내부 단편화:** 할당된 메모리 영역 **안쪽**에 사용하지 못한 공간이 남음
- **외부 단편화:** 비어 있는 공간이 여러 곳에 **흩어져** 있어, 전체 빈 공간은 충분해도 연속 공간 확보가 어려움

## 3. 시험 핵심 정리

- **반입:** 요구 반입(필요한 시점) / 예상 반입(미리)
- **배치:** First Fit(첫 공간) / Best Fit(가장 작은 적합 공간) / Worst Fit(가장 큰 공간)
- **교체:** FIFO·OPT·LRU·LFU 등으로 교체 대상 선택
- **페이징:** 동일 크기, **내부 단편화**
- **세그먼테이션:** 서로 다른 크기의 논리적 단위, **외부 단편화**
