# 기억장치 관리 관련 용어 (Memory Management)

## 1. 스래싱 (Thrashing)

- 필요한 페이지를 메모리에 유지하지 못해 **페이지 부재가 과도하게 발생**하고, 프로세스 처리보다 페이지 교체 및 디스크 입출력에 더 많은 시간을 쓰는 상태이다.
- 전체 시스템 성능이 저하되며, **다중 프로그래밍 정도가 과도할 때** 발생할 수 있다.

### 방지 방법

- **다중 프로그래밍 정도**를 적정 수준으로 유지
- 일부 프로세스의 실행 중단·축소
- 페이지 부재 빈도(**PFF, Page Fault Frequency**) 조절
- **워킹 셋(Working Set)** 유지

## 2. 지역성 (Locality)

프로세스 실행 중 기억장치를 참조할 때 **특정 부분을 집중적으로 참조하는 특성**이다.

| 종류                                | 정의                                                                       | 예시                                                                |
| ----------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| **시간 지역성 (Temporal Locality)** | 최근 참조한 데이터나 명령을 가까운 시간 내에 **다시 참조**할 가능성이 높음 | 반복문(Loop), 스택(Stack), 반복적으로 호출하는 서브루틴(Subroutine) |
| **공간 지역성 (Spatial Locality)**  | 한 위치를 참조하면 그 **인접 위치**도 참조할 가능성이 높음                 | 배열 순회(Array Traversal), 순차적 코드 실행                        |

## 3. 워킹 셋 (Working Set)

- 일정 시간 동안 프로세스가 **자주 참조하는 페이지들의 집합**이다.
- 자주 참조하는 페이지를 주기억장치에 유지하여 페이지 부재와 교체 현상을 줄이고, 주기억장치 사용을 안정화한다.
- 프로세스에 필요한 워킹 셋을 메모리에 충분히 유지하면 스래싱을 방지하는 데 도움이 된다.

## 4. 페이지 부재 (Page Fault)

- 프로세스가 참조하는 **필요한 페이지가 현재 주기억장치에 없는 상황**이다.
- 이때 운영체제는 필요한 페이지를 보조기억장치 등에서 가져와 적재할 수 있으며, 이에 따른 처리 비용이 발생한다.

## 실기 암기 포인트

- 스래싱 = **과도한 페이지 교체 / 시스템 성능 저하**
- 시간 지역성 = **최근에 접근한 곳을 다시 접근**
- 공간 지역성 = **인접한 위치에 접근**
- 워킹 셋 = **최근 일정 구간에서 자주 쓰는 페이지 집합**
- 페이지 부재 = **필요한 페이지가 메모리에 없음**
