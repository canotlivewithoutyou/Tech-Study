# 페이지 교체 알고리즘과 FIFO 기출 예제

## 1. 페이지 교체 알고리즘

주기억장치에 비어 있는 페이지 프레임이 없고, 필요한 페이지가 메모리에 존재하지 않을 때 **교체할 페이지를 선택**하는 알고리즘이다.

| 알고리즘 | 영문 | 교체 기준 |
| --- | --- | --- |
| **OPT** | Optimal | **앞으로 가장 오랫동안 사용되지 않을** 페이지 교체. 페이지 부재 횟수가 최소인 이론적 기준 알고리즘 |
| **FIFO** | First In First Out | **가장 먼저 들어온**, 즉 메모리에 가장 오래 적재된 페이지 교체 |
| **LRU** | Least Recently Used | **가장 오랫동안 사용되지 않은** 페이지 교체(최근 사용 시점 기준) |
| **LFU** | Least Frequently Used | **사용 빈도가 가장 낮은** 페이지 교체 |

> **OPT와 LRU 구분:** OPT는 **미래**의 사용 여부를, LRU는 **과거의 최근 사용 시점**을 기준으로 한다. OPT는 미래 참조 정보를 알아야 하므로 실제 구현보다는 성능 비교 기준으로 활용한다.

### 함께 알아둘 알고리즘: NUR

- **NUR(Not Used Recently)**: 최근 참조 여부 등을 이용해 교체 대상을 선정
- 보통 **참조 비트(R)**와 **변경 비트(M)**를 활용해 교체 후보의 우선순위를 판단

## 2. 페이지 교체에서 사용하는 용어

- **페이지 참조(Page Reference):** 프로그램이 특정 페이지에 접근하려는 것
- **페이지 적중(Page Hit):** 참조한 페이지가 이미 주기억장치에 있음
- **페이지 부재(Page Fault):** 참조한 페이지가 주기억장치에 없어 가져와야 함
- **페이지 프레임(Page Frame):** 물리 메모리에서 페이지를 담는 고정 크기의 공간

## 3. 기출 예제: FIFO 페이지 부재 횟수

**[2020년도 4회 필기 기출 예제]**

> 4개의 페이지를 수용할 수 있는 주기억장치가 있고, 초기에는 모든 프레임이 비어 있다고 가정한다. 다음 참조 순서에서 **FIFO** 페이지 교체 알고리즘을 사용할 경우 페이지 부재 발생 횟수는?

- **페이지 프레임 수:** 4개
- **참조 순서:** `1, 2, 3, 1, 2, 4, 5, 1`

### 풀이

| 순서 | 참조 페이지 | 메모리에 있는 페이지(들어온 순서) | 적중/부재 | 교체된 페이지 |
| ---: | :---: | --- | :---: | :---: |
| 1 | 1 | `[1]` | **부재** | - |
| 2 | 2 | `[1, 2]` | **부재** | - |
| 3 | 3 | `[1, 2, 3]` | **부재** | - |
| 4 | 1 | `[1, 2, 3]` | 적중 | - |
| 5 | 2 | `[1, 2, 3]` | 적중 | - |
| 6 | 4 | `[1, 2, 3, 4]` | **부재** | - |
| 7 | 5 | `[2, 3, 4, 5]` | **부재** | `1` |
| 8 | 1 | `[3, 4, 5, 1]` | **부재** | `2` |

**정답: 페이지 부재 6회**

### 풀이 포인트

1. 처음 등장한 `1, 2, 3`은 메모리가 비어 있으므로 **3회 부재**.
2. 이후 참조된 `1, 2`는 이미 메모리에 존재하므로 **부재 없음**.
3. 새로운 `4`를 넣으면 프레임 4개가 모두 채워져 **1회 부재**.
4. 새로운 `5`가 들어오면 FIFO에 따라 **가장 먼저 들어온 `1`을 교체** → **1회 부재**.
5. 마지막 `1`은 이미 빠져나갔으므로 **가장 오래된 `2`를 교체** → **1회 부재**.
6. 총 `3 + 1 + 1 + 1 = 6회`.

> **시험 함정:** FIFO에서 페이지가 **다시 참조(적중)**되어도 들어온 순서는 변하지 않는다. LRU처럼 참조 시점을 갱신해서는 안 된다.

## 4. 알고리즘 구별 암기

```text
OPT  → 앞으로 가장 오래 안 쓸 페이지 (미래)
FIFO → 가장 먼저 들어온 페이지 (입장 순서)
LRU  → 최근 가장 오래 안 쓴 페이지 (최근 사용 시점)
LFU  → 가장 적게 사용한 페이지 (사용 횟수)
```

**추가 주의:** LFU에서 사용 횟수가 같은 페이지가 여러 개라면, 어떤 페이지를 내보낼지는 문제에서 제시한 **동률 처리 규칙**에 따른다.
