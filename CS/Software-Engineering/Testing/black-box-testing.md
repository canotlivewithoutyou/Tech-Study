# 블랙박스 테스트 (Black Box Test)

## 1. 개념

블랙박스 테스트는 소프트웨어의 내부 구조를 알지 못한 상태에서 **입력과 출력, 기능**을 중심으로 수행하는 테스트다.

- 모듈 내부 구조를 직접 확인하지 않음
- 소프트웨어 인터페이스에서 수행
- 각 기능이 요구사항대로 완전하게 동작하는지 확인
- **기능 테스트(Functional Test)** 라고도 부름

---

## 2. 블랙박스 테스트 종류

### 2.1 동등 분할 검사 (Equivalence Partition)

- 입력 조건을 몇 개의 **동등한 영역**으로 나누어 대표값을 테스트
- 타당한 입력과 타당하지 않은 입력 자료를 균등하게 선정

예:

```text
입력 가능 범위: 1 ~ 100
```

동등 분할 예시:

```text
유효 영역: 1 ~ 100
무효 영역 1: 0 이하
무효 영역 2: 101 이상
```

각 영역의 대표값을 골라 테스트한다.

---

### 2.2 경계값 분석 (Boundary Value Analysis)

- 입력 조건의 **경계값**을 테스트 케이스로 선정
- 오류가 경계에서 자주 발생한다는 점을 이용

예:

```text
조건: 1 이상 100 이하
```

주요 테스트 값:

```text
0, 1, 2, 99, 100, 101
```

#### 자주 보는 경계 표현

- 이상: `>=`
- 이하: `<=`
- 초과: `>`
- 미만: `<`

---

### 2.3 원인-효과 그래프 검사 (Cause-Effect Graphing)

- 입력 데이터 간의 관계와
- 그 입력이 출력에 미치는 영향을

체계적으로 분석한 뒤 효율성이 높은 테스트 케이스를 선택하는 기법

```text
원인(Cause) → 논리 관계 → 결과(Effect)
```

---

### 2.4 오류 예측 검사 (Error Guessing)

- 과거 경험이나 테스터의 감각을 바탕으로
- 오류가 발생할 가능성이 높은 부분을 추정하여 테스트

예:

- 빈 문자열
- Null
- 0
- 최대값/최소값
- 잘못된 형식
- 중복 입력

---

### 2.5 비교 검사 (Comparison Testing)

- 여러 버전의 프로그램에 **동일한 입력**을 넣어
- 같은 결과가 출력되는지 비교

---

## 3. 블랙박스 테스트 한눈에 비교

| 기법 | 핵심 |
|---|---|
| **동등 분할** | 입력 영역을 그룹으로 나누고 대표값 테스트 |
| **경계값 분석** | 범위의 경계 및 경계 주변 값 테스트 |
| **원인-효과 그래프** | 입력과 출력의 논리적 관계 분석 |
| **오류 예측** | 경험을 바탕으로 오류 가능성이 높은 값 선택 |
| **비교 검사** | 여러 버전에 같은 입력을 넣어 결과 비교 |

---

## 4. 동등 분할 vs 경계값 분석

예를 들어 입력 조건이 다음과 같다고 하자.

```text
나이: 20 이상 60 이하
```

### 동등 분할

```text
19 이하      → 무효 영역
20 ~ 60      → 유효 영역
61 이상      → 무효 영역
```

각 영역에서 대표값 몇 개를 선택한다.

### 경계값 분석

```text
19, 20, 21, 59, 60, 61
```

경계와 바로 인접한 값을 집중해서 테스트한다.
