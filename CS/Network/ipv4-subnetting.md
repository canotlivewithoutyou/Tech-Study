# IPv4 주소 체계와 서브넷팅(Subnetting)

## 1. IPv4 주소 체계

- **IPv4 주소**는 총 **32비트**의 이진수로 표현한다.
- 일반적으로 **8비트씩 4개 옥텟(Octet)**으로 나눈 후, 각 옥텟을 십진수로 표현한다.
- 각 옥텟은 **0~255**의 값을 가진다.

**예시: `172.16.254.1`**

| 구분 | 첫 번째 옥텟 | 두 번째 옥텟 | 세 번째 옥텟 | 네 번째 옥텟 |
|---|---|---|---|---|
| 이진수 | `10101100` | `00010000` | `11111110` | `00000001` |
| 십진수 | `172` | `16` | `254` | `1` |

```text
10101100.00010000.11111110.00000001
    172 .   16   .   254  .    1
```

## 2. 서브넷 마스크와 CIDR 표기

**서브넷 마스크(Subnet Mask)**는 IP 주소에서 **네트워크 부분과 호스트 부분을 구분**하는 데 사용한다.

- 마스크의 **1인 비트**: 네트워크 영역
- 마스크의 **0인 비트**: 호스트 영역
- **`/26`**: 32비트 중 앞의 **26비트**가 네트워크 영역이고, 나머지 **6비트**가 호스트 영역이라는 뜻

### `/26`의 예시

```text
서브넷 마스크(이진수)
11111111.11111111.11111111.11000000
<------- 네트워크 26비트 ------><호스트 6비트>

서브넷 마스크(십진수)
255.255.255.192
```

마지막 옥텟 `11000000`을 십진수로 변환하면 다음과 같다.

```text
11000000₂ = 128 + 64 = 192
```

## 3. 서브넷 마스크 비트 수에 따른 변화

아래 표의 **네트워크 개수**는 하나의 `/24` 네트워크를 해당 길이로 나눴을 때를 기준으로 한다. **전체 주소 수**는 한 서브넷에 포함되는 IP 주소의 개수다.

| CIDR | 마지막 옥텟(이진수) | 서브넷 마스크 | 네트워크 개수(/24 기준) | 서브넷당 전체 주소 수 |
|:---:|:---:|:---|---:|---:|
| `/24` | `00000000` | `255.255.255.0` | 1 | 256 |
| `/25` | `10000000` | `255.255.255.128` | 2 | 128 |
| `/26` | `11000000` | `255.255.255.192` | 4 | 64 |
| `/27` | `11100000` | `255.255.255.224` | 8 | 32 |
| `/28` | `11110000` | `255.255.255.240` | 16 | 16 |
| `/29` | `11111000` | `255.255.255.248` | 32 | 8 |
| `/30` | `11111100` | `255.255.255.252` | 64 | 4 |
| `/31` | `11111110` | `255.255.255.254` | 128 | 2 |
| `/32` | `11111111` | `255.255.255.255` | 256 | 1 |

> **주의:** 원본 자료의 '호스트 수' 열에 있는 `256, 128, 64, …`는 **사용 가능한 호스트 수가 아니라 서브넷당 전체 IP 주소 수**로 이해해야 정확하다. 일반적인 서브넷에서는 네트워크 주소와 브로드캐스트 주소를 제외해야 한다.

### 계산 공식

`p` = 서브넷 마스크의 비트 수(CIDR 접두사 길이)

| 구하려는 값 | 공식 |
|---|---|
| 호스트 영역 비트 수 | `32 - p` |
| 서브넷당 전체 IP 주소 수 | `2^(32-p)` |
| 일반적인 서브넷의 할당 가능한 호스트 수 | `2^(32-p) - 2` |
| `/24`를 `/p`로 분할했을 때 서브넷 개수 (`p ≥ 24`) | `2^(p-24)` |

**예: `/26`**

- 호스트 비트 수: `32 - 26 = 6비트`
- `/24` 기준 서브넷 개수: `2^(26-24) = 4개`
- 서브넷당 전체 IP 주소 수: `2^6 = 64개`
- 일반적인 할당 가능 호스트 수: `64 - 2 = 62개`

**예외:** `/31`은 지점 간(Point-to-Point) 링크에서 두 주소를 모두 사용할 수 있으며, `/32`는 단일 IP 주소를 나타낸다. 따라서 `전체 주소 수 - 2` 공식은 `/31`, `/32`에 그대로 적용하지 않는다.

## 4. 네트워크 주소와 브로드캐스트 주소

### 네트워크 주소(Network Address)

- 해당 서브넷의 **첫 번째 IP 주소**
- **호스트 영역의 비트가 모두 `0`**인 주소

### 브로드캐스트 주소(Broadcast Address)

- 해당 서브넷의 **마지막 IP 주소**
- **호스트 영역의 비트가 모두 `1`**인 주소

### 일반적인 할당 가능한 호스트 주소

- 네트워크 주소와 브로드캐스트 주소를 제외한 나머지 주소
- 따라서 일반적인 IPv4 서브넷에서 **할당 가능한 호스트 수 = 전체 주소 수 - 2**

## 5. 기출문제로 이해하기

**[2022년 정보처리기사 실기 2회 기출]**

IP 주소가 `139.127.19.132`이고, 서브넷 마스크가 `255.255.255.192`일 때 다음을 구하시오.

1. 네트워크 주소: `139.127.19.(  )`
2. 네트워크 주소와 브로드캐스트 주소를 제외한 호스트 수

### 풀이 ① 서브넷 마스크 비트 수 확인

```text
255.255.255.192
            ↓
192 = 11000000₂
```

- 앞의 세 옥텟: `24비트`
- 마지막 옥텟 중 네트워크 영역: `2비트`
- 따라서 서브넷 마스크는 **`/26`**이고, 호스트 영역은 **6비트**이다.

### 풀이 ② 네트워크 주소 구하기

마지막 옥텟을 이진수로 표현하고 서브넷 마스크와 **비트 AND 연산**을 수행한다.

```text
IP 주소:       132 = 10000100
서브넷 마스크: 192 = 11000000
                    --------
AND 연산 결과: 128 = 10000000
```

따라서 **네트워크 주소는 `139.127.19.128`**이다.

다음과 같이 **IP 주소 구간**으로 구해도 된다.

- `/26`의 호스트 비트 수: 6비트
- 한 서브넷의 전체 주소 수: `2^6 = 64개`
- 마지막 옥텟의 구간: `0~63`, `64~127`, `128~191`, `192~255`
- 주어진 주소의 마지막 옥텟 `132`는 **`128~191`** 구간에 포함된다.

| 마지막 옥텟 범위 | 네트워크 주소의 마지막 옥텟 | 브로드캐스트 주소의 마지막 옥텟 |
|---|---:|---:|
| `0~63` | 0 | 63 |
| `64~127` | 64 | 127 |
| **`128~191`** | **128** | **191** |
| `192~255` | 192 | 255 |

### 풀이 ③ 할당 가능한 호스트 수 구하기

```text
전체 IP 주소 수: 2^6 = 64개
네트워크 주소:  139.127.19.128
브로드캐스트:   139.127.19.191
할당 가능 범위: 139.127.19.129 ~ 139.127.19.190

할당 가능한 호스트 수 = 64 - 2 = 62개
```

### 최종 정답

| 문항 | 정답 |
|---|---|
| (1) 네트워크 주소 | **`139.127.19.128`** |
| (2) 할당 가능한 호스트 수 | **`62개`** |

## 6. 시험 직전 암기 포인트

- **IPv4 = 32비트 = 8비트 × 4옥텟**
- **`/n` = 네트워크 비트 n개**, 호스트 비트는 `32-n`개
- **서브넷 마스크 1 = 네트워크**, 0 = 호스트
- **서브넷당 전체 주소 수 = `2^(호스트 비트 수)`**
- **일반적인 할당 가능 호스트 수 = 전체 주소 수 - 2** (`/31`, `/32` 예외)
- **네트워크 주소 = 호스트 비트가 전부 0**
- **브로드캐스트 주소 = 호스트 비트가 전부 1**
- **`/26` → `255.255.255.192` → 64개 주소 → 할당 가능 62개**
