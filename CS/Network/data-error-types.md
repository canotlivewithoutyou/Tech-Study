# 코드 오류 유형

## 1. 코드 오류 분류

| 오류 유형          | 영문                 | 설명                            | 예시 (원본 → 오류) |
| ------------------ | -------------------- | ------------------------------- | ------------------ |
| **생략 오류**      | Omission error       | 입력 시 한 자리를 빼놓고 기록   | `ABCD` → `ABD`     |
| **필사 오류**      | Transcription error  | 임의의 한 자리를 잘못 기록      | `ABCD` → `ABFD`    |
| **전위 오류**      | Transposition error  | 입력 시 좌우 자리를 바꾸어 기록 | `ABCD` → `ACBD`    |
| **이중 전위 오류** | Double transposition | 전위 오류가 두 개 이상 발생     | `ABCD` → `CABD`    |
| **추가 오류**      | Addition error       | 입력 시 한 자리를 추가로 기록   | `ABCD` → `ABCDE`   |
| **임의 오류**      | Random error         | 다른 오류가 두 가지 이상 결합   | `ABCD` → `ACBDF`   |

## 2. 암기 포인트

- **생략** → 빠짐
- **필사** → 잘못 씀
- **전위** → 자리 바꿈
- **이중 전위** → 자리 바꿈이 두 번 이상
- **추가** → 더 넣음
- **임의** → 두 종류 이상의 오류가 결합
