# 클라우드 서비스 (Cloud Service)

## 1. 클라우드 서비스 유형

| 유형 | 영문명 | 핵심 개념 |
|:---:|---|---|
| **IaaS** | Infrastructure as a Service | 서버, 네트워크, 스토리지 등 **인프라(물리적 자원)를 가상화**하여 제공 |
| **PaaS** | Platform as a Service | 응용프로그램 개발에 필요한 **플랫폼(OS, 미들웨어, 런타임)** 제공 |
| **SaaS** | Software as a Service | 사용자가 이용하는 **소프트웨어(앱)**를 서비스 형태로 제공 |
| **BaaS** | Blockchain as a Service | **블록체인 기반 서비스**의 개발·관리를 편리하게 지원하는 클라우드 서비스 |
| **SECaaS** | Security as a Service | 클라우드 기반으로 **보안 서비스** 제공 |
| **DaaS** | Desktop as a Service | 업무용 데스크톱 환경(OS 및 SW 등)을 클라우드 방식으로 제공. **재택근무** 등에 활용 |
| **FaaS** | Function as a Service | 복잡한 빌드·유지보수 및 서버 관리 부담을 줄여 **애플리케이션 기능(함수)의 개발·실행·관리**를 지원 |

## 2. IaaS / PaaS / SaaS 비교

| 구분 | IaaS | PaaS | SaaS |
|---|---|---|---|
| **무엇을 제공하나?** | 인프라 | 개발·실행 플랫폼 | 완성된 소프트웨어 |
| **핵심 키워드** | 서버·네트워크·스토리지 | OS·미들웨어·런타임 | 애플리케이션·서비스 이용 |
| **기억할 점** | 인프라를 빌려 사용 | 개발 환경을 제공받음 | 소프트웨어를 바로 사용 |

## 3. 시험 대비 암기 포인트

- **IaaS** → `Infrastructure` → **인프라**
- **PaaS** → `Platform` → **개발 플랫폼**
- **SaaS** → `Software` → **완성된 소프트웨어**
- **BaaS** → `Blockchain` → **블록체인 서비스 개발·관리**
- **SECaaS** → `Security` → **보안 서비스**
- **DaaS** → `Desktop` → **클라우드 데스크톱, 재택근무**
- **FaaS** → `Function` → **함수 단위 실행 및 관리**
