# 기억장치 및 메모리 종류

## 1. 주기억장치: RAM과 ROM

### 1.1 RAM(Random Access Memory)

- 프로그램 실행 중 필요한 **명령어와 데이터**를 저장하는 주기억장치
- **휘발성(Volatile)**: 전원이 꺼지면 저장된 데이터가 사라짐

#### SRAM과 DRAM 비교

| 구분 | SRAM(Static RAM, 정적 RAM) | DRAM(Dynamic RAM, 동적 RAM) |
| --- | --- | --- |
| 속도 | 빠름 | SRAM보다 느림 |
| 집적도 | 낮음 | 높음 |
| 소비 전력 | 일반적으로 큼(같은 용량 기준) | 일반적으로 작음(같은 용량 기준) |
| 재충전(Refresh) | 불필요 | 필요 |
| 대표 용도 | **캐시 메모리** | **주기억장치** |

> **암기:** **SRAM = 빠름 / 리프레시 불필요 / 캐시**, **DRAM = 집적도 높음 / 리프레시 필요 / 주기억장치**

### 1.2 ROM(Read Only Memory)

- **비휘발성(Non-volatile)**: 전원이 차단되어도 저장 내용이 유지됨
- 펌웨어와 같이 시스템에 필요한 기본 프로그램을 보관하는 데 활용
- 종류에 따라 데이터를 기록하거나 지우는 방법이 다름

#### ROM 종류

| 종류 | 특징 |
| --- | --- |
| **Mask ROM** | 제조 과정에서 내용을 기록하며, 제조 후 임의 수정 불가 |
| **PROM** | 사용자가 **한 번만** 기록 가능하며, 이후 일반적으로 읽기만 가능 |
| **EPROM** | **자외선(UV)**으로 저장 내용을 지운 뒤 다시 기록할 수 있음 |
| **EEPROM** | **전기적 신호**로 저장 내용을 지우고 다시 기록할 수 있음 |

#### BIOS와 ROM(펌웨어 관련 개념)

전통적인 PC에서 BIOS(Basic Input/Output System)는 시스템의 초기화와 부팅을 담당하는 펌웨어이다.

- 하드웨어와 소프트웨어 사이에서 기본적인 하드웨어 초기화 기능 수행
- 부팅 시 자체 진단 **POST(Power-On Self-Test)** 수행
- BIOS/펌웨어 설정(CMOS Setup 등)을 통해 날짜, 부팅 순서, 전원 관리, 칩셋·저장장치 설정 등의 값 관리
- 시스템 암호, 기본 입출력 지원, 장치 관련 설정 등의 기능 제공 가능
- **펌웨어 업데이트**를 통해 오류 수정이나 기능 개선 가능
- 일부 전통적인 BIOS에서는 기본 글꼴, 플러그 앤 플레이(PnP), 하드디스크 유형, 바이러스 검사 관련 기능 등을 지원하기도 함

> **정확한 구분:** 위 BIOS 기능은 **ROM 전체의 공통 속성**이 아니라 ROM/플래시 등에 저장되는 **펌웨어**에 관한 설명이다. 현대 PC에서는 기존 BIOS 대신 **UEFI 펌웨어**가 널리 사용된다. BIOS/UEFI의 암호는 Windows 로그인 암호와 별개이다.

## 2. 기타 메모리

| 종류 | 특징 및 용도 |
| --- | --- |
| **레지스터(Register)** | CPU 내부에서 처리할 명령어, 연산 중간 결과 등을 **일시 저장**하는 고속·휘발성 기억장치. 일반적인 기억장치 계층에서 **가장 빠름** |
| **캐시 메모리(Cache Memory)** | CPU와 주기억장치 사이의 속도 차이를 완화. 주로 **SRAM** 사용. **캐시 적중률(Hit Rate)**이 높을수록 평균 메모리 접근 시간이 감소 |
| **가상 메모리(Virtual Memory)** | 보조기억장치를 활용하는 등의 방법으로 프로세스에 **주기억장치보다 큰 가상 주소 공간**을 제공하는 기억장치 관리 기법. **주소 매핑(Mapping)** 필요 |
| **플래시 메모리(Flash Memory)** | 전기적으로 지우고 다시 기록할 수 있는 **비휘발성** 메모리. EEPROM 계열. USB 메모리, SD 카드, SSD 등에 활용 |
| **버퍼 메모리(Buffer Memory)** | 두 장치·프로세스 사이에서 데이터를 **일시 저장**하여 전송 속도나 처리 속도의 차이를 완화 |
| **연관(연상) 메모리(Associative Memory)** | **주소가 아닌 저장된 내용(Content)**을 기준으로 데이터를 검색. 내용 주소화 메모리(CAM)라고도 함 |

### 2.1 플래시 메모리 사용 예

- USB 메모리
- SD 카드
- SSD(NAND Flash)
- MP3 플레이어 및 디지털카메라의 저장장치

### 2.2 캐시 메모리의 핵심 개념

- **캐시 적중(Hit)**: 필요한 데이터가 캐시에 존재하는 경우
- **캐시 미스(Miss)**: 필요한 데이터가 캐시에 없어 하위 기억장치에 접근해야 하는 경우
- **캐시 적중률 증가 → 평균 접근 시간 감소 → 시스템 처리 성능 향상 가능**

### 2.3 기억장치 속도 비교

일반적인 처리·접근 속도 순서:

```text
레지스터 > 캐시 메모리 > 주기억장치(RAM) > 보조기억장치(SSD/HDD 등)
       빠름                                          느림
```

## 3. 시험 핵심 정리

- **휘발성:** RAM(SRAM, DRAM), 레지스터 / **비휘발성:** ROM, 플래시 메모리
- **SRAM ↔ DRAM:** 캐시 ↔ 주기억장치, 빠름 ↔ 상대적으로 느림, Refresh 불필요 ↔ 필요
- **EPROM ↔ EEPROM:** 자외선 소거 ↔ 전기적 소거
- **캐시:** CPU와 RAM의 속도 차이를 완화
- **버퍼:** 데이터 전송·처리 속도의 차이를 완화
- **연관 메모리:** **내용 기반 검색**
- **가상 메모리:** 가상 주소와 물리 주소의 매핑이 필요
