# 사회공학 및 피싱 공격

## 1. 사회 공학 (Social Engineering)

- 컴퓨터 보안에서 인간 상호 작용의 **신뢰**를 이용하여 사람들을 속이고, 보안 절차를 깨뜨리기 위한 **비기술적 침입 수단**

## 2. 피싱 및 유사 공격

| 공격                             | 설명                                                                                                                 |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **큐싱 (Qshing)**                | QR코드를 통해 악성 앱 다운로드를 유도하거나 설치하게 하는 공격                                                       |
| **스피어 피싱 (Spear Phishing)** | 조직 내 특정 개인 또는 그룹을 대상으로 하는 표적형 피싱. 신뢰할 수 있는 발신자가 보낸 것처럼 속여 금융·개인정보 탈취 |
| **스미싱 (Smishing)**            | 문자 메시지(SMS)를 통해 사용자의 개인·신용 정보를 탈취하는 공격                                                      |
| **파밍 (Pharming)**              | DNS 등을 조작하여 정상 금융기관 사이트에 접속한 것처럼 착각하게 해 개인정보 탈취                                     |
| **타이포스쿼팅 (Typosquatting)** | 사용자가 웹 URL 주소를 잘못 입력하는 실수를 악용하는 공격                                                            |
| **웨일링 (Whaling)**             | CEO, 고위 경영진, 유명인사 등 영향력 있는 인물을 타깃으로 하는 스피어 피싱                                           |

### 암기 포인트

- **큐싱** → QR코드
- **스미싱** → SMS 문자 메시지
- **스피어 피싱** → 특정 개인·집단 대상
- **웨일링** → 고위 경영진 등 특정 주요 인물 대상
- **파밍** → DNS 조작·가짜 사이트 유도
- **타이포스쿼팅** → URL 오타 악용
