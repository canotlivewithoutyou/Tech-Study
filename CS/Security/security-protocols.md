# 정보 보안 프로토콜

## 1. 보안 프로토콜 비교

| 프로토콜                                   | 설명                                                                                                                                                                                 | 핵심 키워드           |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------- |
| **SSH** (Secure Shell)                     | 서로 연결된 컴퓨터 간 원격 명령 실행 및 셸 서비스 수행. 공개키 인증을 사용하는 경우 클라이언트의 공개키를 서버에 등록해야 함. 전송 데이터가 암호화되며 기본적으로 **22번 포트** 사용 | 원격 접속, 암호화, 22 |
| **SSL** (Secure Socket Layer)              | 웹 브라우저와 서버 간 안전한 데이터 전송을 목적으로 사용. HTTPS와 관련되며 **443번 포트** 사용                                                                                       | 웹 통신 보안, 443     |
| **TLS** (Transport Layer Security)         | 인터넷 커뮤니케이션을 위한 개인정보 보호와 데이터 무결성을 제공하는 보안 프로토콜. **SSL의 개선 버전**                                                                               | SSL 개선, 무결성      |
| **IPSec**                                  | IP 네트워크 계층을 안전하게 보호하기 위한 보안 프로토콜                                                                                                                              | 네트워크 계층 보안    |
| **S-HTTP**                                 | 웹상에서 네트워크 트래픽을 암호화하기 위한, 기존 HTTP의 보안 확장 방식                                                                                                               | HTTP 보안 확장        |
| **TKIP** (Temporal Key Integrity Protocol) | 임시 키 무결성 프로토콜. WEP의 취약성을 보완하기 위해 암호 알고리즘에 사용하는 키 길이를 128비트로 늘린 방식                                                                         | WEP 보완, 128비트     |

## 2. IPSec의 동작 모드

| 구분                           | 설명                                                                                |
| ------------------------------ | ----------------------------------------------------------------------------------- |
| **전송 모드 (Transport Mode)** | 패킷의 페이로드를 보호하는 방식. 원본 IP 헤더는 유지되어 통신 경로가 노출될 수 있음 |
| **터널 모드 (Tunnel Mode)**    | 원본 IP 패킷 전체를 보호하고 새 IP 헤더를 추가하는 방식                             |

## 3. IPSec의 보안 프로토콜

- **AH (Authentication Header)**: 인증과 무결성 검증을 제공하는 프로토콜
- **ESP (Encapsulating Security Payload)**: 암호화 및 인증·무결성 보호에 사용되는 프로토콜

### 암기 포인트

- **SSH = 22번 포트**
- **HTTPS = 443번 포트**
- **TLS = SSL의 개선 버전**
- **IPSec = 전송 모드 / 터널 모드, AH / ESP**
- **TKIP = WEP 취약성 보완**
