# 웹·네트워크 공격 기법

## 1. 웹 애플리케이션 공격

| 공격                                  | 설명                                                                                                                              |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **XSS** (Cross-Site Scripting)        | 브라우저 스크립트 취약점을 악용. 특정 링크를 클릭하거나 취약한 페이지를 열 때 악성 스크립트가 실행되어 개인정보 탈취 등 피해 유발 |
| **CSRF** (Cross-Site Request Forgery) | 사용자가 공격자가 의도한 행위(수정, 삭제, 등록 등)를 특정 웹사이트에 요청하게 하는 공격                                           |
| **SQL 삽입 공격** (SQL Injection)     | 임의의 SQL 문을 주입·실행하여 데이터베이스가 비정상적인 동작을 하도록 조작하는 코드 삽입 공격                                     |
| **제로 데이 공격** (Zero-day Attack)  | 발견된 취약점에 대한 패치나 대응책이 마련되기 전에 해당 취약점을 이용하는 공격                                                    |

## 2. 네트워크 공격

| 공격                                  | 설명                                                                                                                                   |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **스니핑 (Sniffing)**                 | 네트워크 패킷을 엿보면서 계정 정보(ID/PW) 등을 가로채는 행위                                                                           |
| **스푸핑 (Spoofing)**                 | 신뢰할 수 있는 사용자·장치·주소인 것처럼 위장하여 데이터를 변조하거나 접속을 시도하는 속임수                                           |
| **세션 하이재킹 (Session Hijacking)** | 서버에 접속하고 있는 클라이언트의 세션 정보를 가로채는 공격. Reset 패킷으로 연결을 강제 종료시킨 후 재연결 과정에 개입하는 방식도 존재 |
| **블루버그 (Bluebug)**                | 블루투스 연결 취약점을 이용하는 공격                                                                                                   |

### 스푸핑 종류

| 유형             | 설명                                          |
| ---------------- | --------------------------------------------- |
| **IP Spoofing**  | 공격자가 자신의 IP 주소를 다른 주소로 위장    |
| **ARP Spoofing** | 공격자의 MAC 주소를 다른 컴퓨터의 주소로 위장 |
| **DNS Spoofing** | DNS 응답의 IP 주소를 중간에서 조작하여 위장   |

## 3. 기타 공격 기법

| 공격                                      | 설명                                                                                          |
| ----------------------------------------- | --------------------------------------------------------------------------------------------- |
| **버퍼 오버플로우 (Buffer Overflow)**     | 할당된 메모리의 범위를 넘어선 위치에 자료를 기록하거나 접근할 때 발생하는 오류·취약점         |
| **무차별 대입 공격 (Brute Force Attack)** | 가능한 모든 문자열·키 조합을 시도하여 암호나 인증 정보를 알아내는 공격                        |
| **워터링 홀 공격 (Watering Hole Attack)** | 타깃이 자주 방문하는 웹사이트를 감염시킨 뒤 해당 타깃이 방문할 때까지 기다리는 공격           |
| **크리덴셜 스터핑 (Credential Stuffing)** | 여러 경로로 수집한 사용자의 로그인 인증 정보를 다른 사이트의 계정 로그인에 대입하는 공격      |
| **아일랜드 호핑 (Island Hopping)**        | 타깃 기업을 침해하기 위해 보안이 더 취약한 협력사·파트너 기업의 네트워크를 먼저 해킹하는 공격 |

### 암기 포인트

- **XSS** → 악성 **스크립트 실행**
- **CSRF** → 사용자에게 **원치 않는 요청** 수행 유도
- **SQL Injection** → SQL 문 삽입
- **스니핑** → 패킷 **도청**
- **스푸핑** → 주소·신원 **위장**
- **세션 하이재킹** → **세션 탈취**
- **버퍼 오버플로우** → 메모리 경계 초과
- **크리덴셜 스터핑** → 유출된 로그인 인증 정보 **재사용**
