# 정보 보안 기본 개념

## 정보 보안 3대 요소

### 기밀성 (Confidentiality)
- 시스템 내 정보 자원은 인가된 사용자에게만 접근을 허용한다.

### 무결성 (Integrity)
- 오직 인가된 사용자만이 시스템 내 정보를 수정할 수 있다.

### 가용성 (Availability)
- 인가된 사용자는 권한 범위 내에서 언제든 자원에 접근할 수 있다.

### 추가 개념
- **인증**: 사용자의 신분 확인
- **부인방지**: 부인할 수 없도록 송·수신 증거 제공

---

## AAA (Triple-A)

### 인증 (Authentication)
- 사용자가 네트워크 접속 전에 시스템에서 사용자 신원을 확인한다.

### 권한부여 (Authorization)
- 검증된 사용자에게 사용 가능한 접근 권한을 부여한다.

### 계정관리 (Accounting)
- 사용자의 자원 사용에 대한 정보를 수집한다.
- 과금, 감사, 보고서 등에 활용한다.
