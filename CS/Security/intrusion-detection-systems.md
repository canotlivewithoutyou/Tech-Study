# 침입 탐지 시스템 (IDS)

## 1. IDS (Intrusion Detection System)

- **정의**: 시스템의 비정상 사용, 오용, 남용 등을 실시간 탐지하는 시스템

### 탐지 방식

| 구분          | 설명                                                                      |
| ------------- | ------------------------------------------------------------------------- |
| **오용 탐지** | 사전에 정립되어 입력해 둔 공격 패턴을 감지하면 통보                       |
| **이상 탐지** | 평균적인 상태를 기준으로 비정상적인 행위 또는 자원의 사용을 감지하면 통보 |

### IDS 종류

| 구분                         | 특징                                                                                     | 대표 도구                     |
| ---------------------------- | ---------------------------------------------------------------------------------------- | ----------------------------- |
| **HIDS** (Host-based IDS)    | 시스템 내부 감시·분석. 내부 변화를 실시간으로 감시하여 외부 침입자의 작업을 기록 및 추적 | OSSEC, md5deep, AIDE, Samhain |
| **NIDS** (Network-based IDS) | 외부 침입 감시·분석. 네트워크 트래픽 감시                                                | Snort, Zeek                   |

### IDS 설치 가능 위치

- 패킷이 라우터로 들어오기 전
- 라우터 뒤
- 방화벽 뒤
- DMZ

> **DMZ (Demilitarized Zone)**: 외부 인터넷에 서비스를 제공하는 서버가 위치하는 네트워크
